# GeoShield Saudi — الأحساء والخفجي

الموقع الرسمي لفروع **GeoShield** في الأحساء والخفجي، مبني كموقع Static سريع وخفيف ومهيأ للنشر عبر GitHub Pages.

## الروابط

- الموقع: https://aveni-cmd.github.io/geoshield/
- المستودع: `AVENi-cmd/geoshield`
- الفرع الرئيسي: `main`

## التقنية

- HTML5 دلالي
- CSS حديث ومتجاوب بدون إطار عمل
- JavaScript خفيف بدون مكتبات خارجية
- GitHub Pages
- IBM Plex Sans Arabic
- صور WebP محسنة
- Structured Data بصيغة JSON-LD
- Open Graph / Twitter metadata
- Sitemap + Image Sitemap

## قواعد المحتوى التي لا تُغيّر دون اعتماد

- الأسعار المعروضة في الموقع لا تشمل ضريبة القيمة المضافة.
- ضمان PPF والعازل الحراري: **بلا حدود** وفق شروط الضمان.
- نانو سيراميك 9H: **3 + 5 سنوات** — 3 سنوات للتطبيق و5 سنوات للطبقات.
- الصيانة الدورية كل **6 شهور** جزء من المحافظة على الضمان.
- بعد PPF أو السيراميك: **7 أيام بدون غسيل**.
- بعد تركيب العازل الحراري: **48 ساعة بدون فتح النوافذ**.
- **4 ساعات** بدون مواد كيميائية أو مطر.
- فحص مجاني خلال **4 أسابيع**.
- الملكية المعتمدة في التذييل: `الوكالة معتمدة ومملوكة لمؤسسة عواد الظفيري`.

## ملاحظات تطوير مهمة

1. لا تستخدم صورًا للفروع؛ بطاقات الفروع مصممة بدون صور.
2. صور الـHero معتمدة بنسبة `2.5:1` وبأبعاد `1920×768` للشرائح الرئيسية.
3. لا تستخدم `object-fit: cover` للصور التي تحتوي نصًا أو عناصر مهمة؛ الأولوية لعدم القص.
4. حافظ على RTL للعربية وعلى أرقام الهواتف باتجاه LTR.
5. أي تعديل على ساعات العمل يجب تحديثه في ثلاثة أماكن معًا:
   - النص الظاهر في `index.html`
   - منطق `officialHours` داخل `script.js`
   - `openingHoursSpecification` داخل JSON-LD
6. أي تعديل على فرع أو رقم هاتف يجب مراجعته أيضًا في نموذج الحجز وشريط الإجراءات السريعة.
7. يجب احترام `prefers-reduced-motion` في أي حركة جديدة.
8. لا تُضاف مكتبات أو أطر عمل ثقيلة ما لم توجد حاجة حقيقية لها.

## الحجز

نموذج الحجز لا يحتاج حسابًا أو خادمًا خلفيًا. بعد التحقق من البيانات، يُنشئ رسالة منظمة ويفتح واتساب الخاص بالفرع المحدد. رقم الجوال يقبل الأرقام العربية والإنجليزية وصيغ `+966` و`966` ثم يُوحّد إلى الصيغة السعودية المحلية.
